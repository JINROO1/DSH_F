# DSH_F 0.1.0 — Fedora Edition

Shell de escritorio para Fedora KDE Plasma sobre el motor oficial **DeepSeek Harness**. Edición comunitaria **no afiliada a DeepSeek**. No se parchea el paquete oficial de Harness: las mejoras viven en la capa Fedora/Electron y las credenciales siguen en el flujo oficial del motor.

## Instalar

```bash
sha256sum -c SHA256SUMS
sudo dnf install -y ./dsh-fedora-0.1.0-x86_64.rpm
```

El RPM instala en `/opt` y registra `dsh-fedora.desktop`. Las dependencias de Electron/Chromium se resuelven con `dnf`. Guía completa: [docs/FEDORA.md](https://github.com/JINROO1/DSH_F/blob/v0.1.0/docs/FEDORA.md).

> **Sin firma criptográfica.** Esta release no está firmada con GPG/sigstore: la fase 5.3 sigue bloqueada hasta tener claves fuera del repositorio y un proceso de rotación/revocación. La verificación disponible es **SHA-256 + procedencia del CI**.

## Qué incluye (Fases 0–7)

- **Fase 1 — Accesibilidad:** paleta clara accesible, semántica/foco, matriz axe 12/12 y 20 tests de contraste.
- **Fase 2 — Onboarding:** guía descartable, estado de credenciales/permisos, recuperación y logs filtrables con redacción.
- **Fase 3 — Actualizaciones:** comprobación **manual y de solo lectura** en CLI y app. Sin auto-update silencioso ni telemetría obligatoria.
- **Fase 4 — Fedora/KDE:** bandeja StatusNotifier con degradación, cerrar a bandeja, autostart XDG, notificaciones nativas genéricas silenciables, matriz Fedora y ADR de distribución.
- **Fase 5 — Cadena de suministro:** SBOM, licencias estrictas, auditoría de dependencias y ADRs de permisos/llavero.
- **Fase 6 — Productividad:** paleta de comandos ampliada, favoritos/alias y rutas rotas, plantillas locales, backup de preferencias con vista previa y `.bak`, interfaz es/en y línea base de rendimiento.
- **Fase 7 — Comunidad:** `CONTRIBUTING.md`, plantillas de issue/PR, ADRs, checklist de release y triaje mensual.

Detalle por subfase: [docs/ROADMAP.md](https://github.com/JINROO1/DSH_F/blob/v0.1.0/docs/ROADMAP.md).

## Limitaciones conocidas (bloqueos externos)

No se marcan como resueltas porque dependen de hardware, cuentas o decisiones humanas:

- **Fedora/Plasma real (1.8, 4.1):** matriz en Wayland/X11, bandeja, suspensión, lectores de pantalla y zoom/alto contraste pendientes en equipo real. La instalación en contenedor **no** sustituye esta validación.
- **Upgrade/rollback RPM (4.4):** requiere una versión anterior instalada en Fedora real. Procedimiento documentado en `docs/FEDORA.md`.
- **Firma criptográfica (5.3):** bloqueada (claves fuera del repo + rotación/revocación).
- **COPR / repositorio de paquetes:** aplazado según ADR 0001; no se publica un repo experimental como estable.
- **Llavero del sistema:** aplazado (ADR 0003); las credenciales no se migran fuera del flujo oficial de Harness.
- **UI avanzada de permisos:** aplazada (ADR 0002) hasta confirmar el contrato upstream.
- **Optimización de iframe/runtime:** no aplicada. Solo existe línea base medida (3 runs, WebSocket verificado).

## Upgrade y rollback

```bash
# Upgrade conservando datos
sudo dnf install -y ./dsh-fedora-0.1.0-x86_64.rpm

# Rollback
sudo dnf downgrade dsh-fedora
# o reinstalar el RPM anterior conservado
sudo dnf install -y ./dsh-fedora-VERSION_ANTERIOR-x86_64.rpm
```

Los datos del usuario (`userData`, `DSH_HOME`, proyectos) no se borran al actualizar o revertir. Si el motor no arranca, exporta el diagnóstico desde la app y revisa `docs/ONBOARDING.md`.

## Privacidad

Sin telemetría obligatoria. Las notificaciones son opcionales y genéricas (no incluyen rutas, mensajes del motor ni secretos). El diagnóstico omite la URL del puente y redacta los logs. La comprobación de actualizaciones es de solo lectura y no envía datos del usuario.

Bugs y mejoras: [issues](https://github.com/JINROO1/DSH_F/issues) con plantilla. Vulnerabilidades: aviso **privado** según [SECURITY.md](https://github.com/JINROO1/DSH_F/blob/v0.1.0/SECURITY.md), no en issues públicos.
